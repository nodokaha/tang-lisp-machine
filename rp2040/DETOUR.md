# 寄り道の記録：MacroPad RP2040 に TangLisp を載せた（2026-11-22夜〜11-23未明）

清涼の判断（2026-11-23）で、MacroPad はいったん「なかったこと」にして
ロードマップから外す。コードと成果物はこのフォルダに残る。
戻りたくなったら、この記録から再開できる。

## やったこと（全部実機で確認済み）

- TangLisp 本体（lisp-sd/lisp_sd.c）を RP2040 に移植。生成器は
  `make_rp2040.py`（UART→USB stdio、SDLOW→スタブに差し替え）。
  ヒープ 16,384 セル、バイト列アリーナ 32KB。REPL のみ（SD なし）。
- スマホ Termux から BOOTSEL ドライブへ UF2 を直接書く道具
  （`../phone/uf2_wrap.py`、VID:PID 2e8a:0003 以外には書かない安全ゲート付き。
  BOOTSEL のデータ開始 LBA は 292）。
- OLED（SH1106／SPI1）にスプラッシュ→後にコンソール化。
  21文字×5行で REPL の入出力がそのまま流れる。
- `(keys)`／`(enc)` プリミティブ：12キー＋エンコーダ押し込みの
  ビットマスクと、エンコーダ位置を Lisp から読める。
- パッド単体で式入力：エンコーダでトークン表（38種）を選び、
  押し込みで追加、KEY11＝バックスペース、KEY12＝実行。
  KEY1〜10 はクイックトークン。

## ハマった2件（教訓として本体側にも効く）

1. **Pico SDK 2.x は stdio を自動初期化しない**。main の頭で
   `stdio_init_all()` を呼ばないと USB が一切列挙されない
   （ELF からドライバごと消える）。CPU と REPL は正常に回るので
   気づきにくい。
2. **タグ付きポインタの配列は配置を明示する**。`cells` 配列が
   8バイト境界から4ずれると、全ての値が bytes に化けて
   `(+ 1 1)` が `#<bytes 配列のアドレス>` になる。
   `__attribute__((aligned(8)))` で修正（lisp_sd.c 本体にも反映済み）。

## なぜ外すか

- Tang Primer 25K とは USB でつながらない（Dock の Type-C は
  BL616 デバッガ専用で、FPGA に USB は配線されていない）。
  つなぐなら STEMMA QT（I2C）→ PMOD への配線が要る。
- NXP（FRDM-MCXN947）とは Type-C でつながる（USB ホストになれる）。
  用途案だけ残す：心拍サーバーの操作盤、HID キーパッド、
  I2C の従属パネル。
